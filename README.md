## What's inside

- **Projects:** data analysis, data warehousing, and web apps, each with a short story about the problem, what I did, and the results.
- **Skills:** the tools and techniques I actually use, from SQL and Python to Spring Boot and PHP.
- **About & Experience:** a bit about me, my studies, and the projects where I led the team.
- **Contact:** email, LinkedIn, GitHub, and a downloadable CV.

## A few details I had fun building

- A dot-grid background drawn on `<canvas>` that waves slowly, moves away from your cursor, and ripples when you click.
- Project previews that float next to your cursor when you hover over a project name.
- Small project mockups drawn with plain HTML and SVG instead of image files.
- Dark mode by default, with a toggle for light mode that remembers your choice.
- Animations turn off automatically if your device has "reduce motion" enabled.

## Built with

Plain **HTML, CSS, and JavaScript**. No frameworks, no build step, so it loads fast and works on GitHub Pages as is.

## Project structure

```
.
├── index.html   # page layout and content
├── style.css    # styles, dark/light theme, responsive layout
├── script.js    # project data, background animation, interactions
├── cv.pdf       # downloadable CV
└── preview.png  # screenshot used in this README
```

## Run it locally

No install needed. Either:

- open `index.html` directly in your browser, or
- use the **Live Server** extension in VS Code for auto-reload while editing.

## Editing projects

All project data lives in the `PROYEK` array at the top of `script.js`. To add a project, copy one of the existing entries and change the title, description, tech stack, and links.
